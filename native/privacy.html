# EasyNode Terminal Privacy Policy / 隐私政策 Last updated / 最后更新：2026-08-27 ## 中文 EasyNode Terminal（以下简称“本 App”）是 EasyNode 的移动客户端。本 App 需要连接由用户自行部署或指定的 EasyNode 服务端。 ### 开发者不收集数据 开发者不会通过本 App 收集、出售或将用户数据用于跟踪、广告或分析。本 App 未集成广告、分析或崩溃报告 SDK。 ### 设备本地保存的数据 为了提供登录和管理功能，本 App 可能在用户设备上保存以下信息： - 用户添加的 EasyNode 服务端地址与连接配置； - 用户提供的账户信息、认证凭据和令牌； - App 偏好设置。 凭据和令牌使用系统提供的安全存储能力保存。开发者无法访问这些本地数据。 ### 用户指定的服务 使用本 App 时，登录信息、服务器数据、SSH/SFTP 操作内容和其他请求会发送到用户自行指定的 EasyNode 服务端。若用户启用 AI 功能，相关内容可能发送到用户自行配置的 AI 服务提供商。这些传输是实现用户主动请求功能所必需的；数据处理方式由用户选择的服务及其隐私政策决定。 用户手动检查更新时，本 App 会请求 EasyNode 的公开版本信息文件。此请求仅用于判断是否有新版本，不用于广告、分析或跨 App 跟踪。 ### 文件访问 只有在用户主动选择文件进行上传时，本 App 才会访问所选文件。文件会发送到用户指定的服务器，不会发送给开发者。 ### 安全 本 App 采取合理措施保护设备上保存的信息。用户应负责其 EasyNode 服务端、网络、账户和凭据的安全，并优先使用 HTTPS 等安全连接方式。 ### 儿童隐私 本 App 面向服务器管理用户，不以儿童为目标用户。开发者不会有意收集儿童的个人数据。 ### 政策变更 本政策可能随功能或法律要求变化而更新，并在本页面标明最后更新日期。 ### 联系方式 如对本隐私政策有疑问，请联系：bitkuang888@gmail.com --- ## English EasyNode Terminal (the “App”) is a mobile client for EasyNode. It connects to an EasyNode server deployed or selected by the user. ### No data collected by the developer The developer does not collect or sell user data through the App and does not use user data for tracking, advertising, or analytics. The App does not include advertising, analytics, or crash-reporting SDKs. ### Data stored on the device To provide sign-in and management features, the App may store the following information on the user's device: - EasyNode server addresses and connection settings added by the user; - Account information, authentication credentials, and tokens provided by the user; - App preferences. Credentials and tokens are stored using operating-system secure storage. The developer cannot access this locally stored data. ### User-selected services When the App is used, sign-in information, server data, SSH/SFTP operation content, and other requests are sent to the EasyNode server selected by the user. If the user enables AI features, relevant content may be sent to an AI provider configured by the user. These transfers are necessary to perform features requested by the user. Data handling is governed by the selected services and their privacy policies. When the user manually checks for updates, the App requests EasyNode's public version-information file. This request is used only to determine whether a newer version is available and is not used for advertising, analytics, or cross-app tracking. ### File access The App accesses a file only after the user selects it for upload. The selected file is sent to the server chosen by the user and is not sent to the developer. ### Security The App uses reasonable measures to protect information stored on the device. Users are responsible for securing their EasyNode servers, networks, accounts, and credentials and should prefer secure connections such as HTTPS. ### Children's privacy The App is intended for server-management users and is not directed to children. The developer does not knowingly collect personal data from children. ### Changes to this policy This policy may be updated as features or legal requirements change. The latest revision date will be shown on this page. ### Contact For questions about this Privacy Policy, contact: bitkuang888@gmail.com
